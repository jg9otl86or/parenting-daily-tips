# 西红柿搭配什么好

> 更新时间：2026-09-15 (UTC+8)

西红柿搭配什么好

西红柿搭配什么吃最营养?西红柿炒鸡蛋、番茄炖牛肉等我们就吃多了，其实西红柿还有很多营养搭配，如西红柿鳄梨沙拉、西红柿炒菜花、番茄烧茄子等。番茄的九种搭配营养翻倍，我们一起来看看西红柿搭配什么吃最营养。

**目录**

1**吃西红柿有神效**

　　研究人员发现，这些男子精液中番茄红素含量分别增长7%至12%不等。目前已知不育男性精液中番茄红素含量较低。因此研究人员认为，男性生育力增强与番茄红素含量增高有关。

　　这一成果已发表在《英国泌尿学杂志》上。目前尚不清楚番茄红素对生育力起到何种作用。研究人员推测，番茄红素所含抗氧化剂可能会杀死人体内对生育力有害的化学物质。

　　西红柿为茄科植物，产于全国各地。其味甘、酸，性微寒。除大家熟知的含有大量的维生素有美容的功效外，还有疗疾十法：

　　(一)治皮肤病。将鲜熟西红柿去皮和籽后捣烂敷患处，每日2-3次，治真菌、感染性皮肤病。

　　(二)美容、防衰老。将鲜熟西红柿捣烂取汁再加少许白糖，每天用其涂面，能使皮肤细腻光滑，美容防衰老效果极佳。

　　(三)防癌。因西红柿不仅营养丰富，且具有较强的清热解毒，抑制病变功效，坚持每天吃1-2个鲜熟的西红柿，可起到防癌和辅助治疗癌症的作用。

　　(四)治高血压。每天早晨选1-2个鲜熟西红柿空腹蘸白糖吃，降血压效果明显。

　　(五)治贫血。将西红柿和苹果各一个，芝麻15克，一次吃完，每日吃1-2次，长期坚持可治贫血。

　　(六)治溃疡。轻度消化性溃疡患者，可将榨取的西红柿和马铃薯汁各半混合后饮用，每天早晚一次，连服10次，溃疡可愈。

　　(七)治肝炎。取西红柿丁一匙、芹菜末、胡萝卜末、猪肉各半匙，拌入沸粳米粥内煲熟，加入盐、味精适量食用，对治疗肝炎效果极佳。

　　(八)防中暑。将1-2个西红柿切片，加盐或糖少许，熬汤热饮，可防中暑。

　　(九)退高烧。将西红柿汁和西瓜汁各半杯混合饮用，每小时饮一次，可退高烧。

　　(十)治牙龈出血。将西红柿洗净当水果吃，连吃半个月，当可治愈牙龈出血。

2**西红柿搭配什么好**

　　一、番茄和鸡蛋

　　番茄中的谷胱甘肽有推迟细胞衰老，增加人体抗癌能力的作用，而番茄红素则具有抗氧化力，能够保护细胞，防止细胞癌变。鸡蛋含有维生素、蛋白质和丰富的蛋白质。其中的卵磷脂、固醇类、蛋白质和各种维生素有利于促进神经系统的功能，所以，鸡蛋是很好的健脑食品。而鸡蛋和番茄的结合，形成了营养素的互补，不仅健脑抗衰老，而且开胃健脾。

　　推荐食谱：西红柿炒鸡蛋

　　材料：西红柿、鸡蛋、食盐、白糖、小葱、植物油。

　　做法：

　　1、将西红柿洗净后用沸水烫一下，去皮、去蒂，切片待用。用沸水烫西红柿是一个小窍门，时间几秒钟就可以了，西红柿皮就可以很轻松的被撕下来。

　　2、将鸡蛋打入碗中，加盐，用筷子充分搅打均匀待用;锅里放油3汤匙烧热，将鸡蛋放入锅中炒熟盛出待用;将剩余的油烧热，下西红柿片煸炒，放盐、糖炒片刻，倒入鸡蛋翻炒;翻炒几下出锅即成，可以稍微加点葱花配配色。

　　二、番茄和鳄梨

　　番茄富含茄红素，茄红素和油一起摄取，吸收效果会更好。别称“天然黄油”的鳄梨富含不饱和脂肪酸，和番茄一起做成水果沙拉吃，可谓“天作之合”，鳄梨所含的天然脂肪能提高茄红素的吸收率。

　　推荐食谱：西红柿鳄梨沙拉

　　材料：西红柿1/4个、鳄梨1/4个、盐少许、黑胡椒少许、橄榄油1/2小勺、酸味奶油25g、牛奶1/2大勺、葡萄酒醋1/2小勺。

　　做法

　　1、把西红柿和鳄梨切成小块，撒上盐、黑胡椒和橄榄油，搅匀。把酸味奶油和牛奶混合在一起。

　　2、把酸味奶油和牛奶的混合物放在碟子上，然后放上西红柿、鳄梨，最后浇上葡萄醋。

　　三、番茄和菜花

　　这道菜非常适合老年人吃，是一道开胃佳肴。番茄具有健胃消食、养阴生津的功效，菜花含有大量钾、钙、叶酸和硒，也是纤维素的极佳来源，有帮助消化、增强食欲、防治便秘的功效。菜花和番茄一起吃，还有助预防前列腺癌。

　　推荐食谱：西红柿炒菜花

　　材料：菜花、西红柿、鸡精、植物油、葱姜蒜、白糖等。

　　做法：

　　1、菜花洗净劈成小朵，用热水焯一下，捞出过凉水，控净水备用。西红柿洗净去皮，切成小块;葱蒜洗净切碎备用。

　　2、锅中加入适量油爆香葱蒜碎，放入西红柿煸炒成酱，放焯好的菜花，加少许水翻炒一下，加入适量盐、鸡精、糖，大火将汤汁收干，勾芡出锅即可。

　　四、番茄和牛肉

　　红肉是铁元素的重要来源，而牛肉中铁含量尤其丰富，遇到富含番茄红素和维生素C的番茄后，牛肉中的铁能够更好地被人体吸收。而在炖牛肉时，加上些番茄，还能让牛肉更快变烂，缩短烹调时间。

　　推荐食谱：番茄牛肉汤

　　材料：牛肉400克、土豆3个、胡萝卜2个、葱头4个、鲜豌豆10克、番茄汁10克、枸杞子30克、油80克、花椒、食盐适量。

　　做法：

　　1、先将牛肉洗净，切小片备用。再将胡萝卜洗净切片，葱头切片，豌豆洗净。如无番茄汁，将番茄用开水烫去籽和皮，剁碎压汁亦可。将土豆去皮切小块。

　　2、锅内放油，将牛肉下锅煸至变色，加放2个葱头片、番茄汁和枸杞子，加水没过牛肉约3厘米处，用大火煮沸，改用小火炖约2小时。然后待牛肉、土豆等炖至微软时，放盐入味炖烂，并用2调羹面粉放在汤里，成糊状，加入味精调味即成。

　　五、番茄和茄子

　　做茄子最痛苦的事是它很容易吸油。但有番茄就不同了。这道菜能融合番茄的酸和茄子的嫩，将二者营养合二为一，既除去了红烧茄子的油腻，又中和了番茄的酸气，味美色香。

　　推荐食谱：番茄烧茄子

　　材料：茄子1个、樱桃番茄10个、柿子椒半个、蒜若干瓣、番茄酱、植物油若干。

　　做法：

　　1、将茄子洗净，切块。注意每块茄子的大小要尽量相仿，并且不要削皮。将植物油烧热后倒进茄子块，中火煎制一分钟左右转至快炒。快炒至茄子有七八成熟之后捞起。

　　2、将樱桃番茄切块之后倒进锅里，利用剩余的油快速翻炒一下。樱桃番茄快八成熟的时候倒进刚刚炒好的茄子块，一起翻炒几下。倒入调味料(番茄酱、盐)。将要起锅的时候，把切好的柿子椒(切成条状)和蒜瓣一起倒进，再爆炒一至两分钟，起锅即可。

　　六、番茄和土豆

　　番茄和土豆一起煮可以防治高血压，因为两种原料有一个共同的特点，都含有丰富的钾，钾能促进血中钠盐的排出，有降压、利尿、消肿作用，对高血压、肾脏病有良好的辅助治疗作用。

　　推荐食谱：蒜香番茄炒土豆片

　　材料：土豆1个、番茄1个、大蒜4瓣、香菜(随意)、盐1/2茶匙(3克)。

　　做法：

　　1、把土豆去皮，切成薄片放入清水中浸泡。番茄洗净后去蒂，切成块。大蒜去皮，切成片备用。香菜洗净后，切成1厘米长的段。

　　2、锅中倒入油大火加热，待油4成热时放入一半的大蒜片，煸炒出香味后，放入土豆片翻炒，一直炒到土豆片变成透明色。放入番茄块，炒到番茄变软出汤后，放入盐翻炒均匀，关火后放入香菜段，和另一半的大蒜片翻炒几下出锅即可。

3**生吃西红柿真的可能致命吗**

　　以前只听说过没成熟的青番茄有毒，现在说即便是成熟的番茄也不能生吃，吓得很多中老年人不敢再拿生番茄(包括樱桃番茄)当水果吃。

　　首先需要告诉大家的是，多数植物中都含有数量不等的毒性物质，这是植物的自我保护机制。

　　祖先用“神农尝百草”的方式替我们试过了各种植物，其中毒性小的那些才被筛选出来，当成蔬果日常食用，而在人类栽培育种过程中，又逐渐地降低了其中的有害物质含量。所以，一定要清楚：含有毒素，不等于引起中毒;毒性大小都是有剂量效应关系的，只要含量足够少就是安全的。

　　茄科植物包括番茄、青椒、茄子和土豆都含有毒的生物碱，但成熟番茄中的含量非常低，生吃一斤也不可能到引起中毒的程度。其中所谓“美国人不吃生番茄”的说法，就像“外国人都不用微波炉”一样，是纯正的谣言。爱吃凉拌番茄和樱桃番茄的人们继续吃吧。

　　幸福的润润7：如果是熟透的番茄，生吃是无妨的，如果是未熟的，建议不要生吃。我自己亲身经历：吃完一个八分熟的生番茄，不到半小时，胃痛难忍，脸色煞白，浑身冒虚汗。

　　其实，对某种食物的不良反应，人与人之间会差异甚大。就像有些人吃一口蚕豆就致死，一粒花生就过敏，一只大虾就腹痛，对土豆、辣椒、菠萝、猕猴桃等等很多食物也有人过敏或不耐受。别说青色番茄，即便熟透的番茄，也有人多吃点就会腹泻。这说明身体不适合吃这种食物，那么暂时就不要再吃了，过一年半年再试试。但这不意味着所有人都不能吃生番茄。

　　食物的所谓“毒性”，可以是非常慢性的影响，也可以是非常快速的中毒效果。如果是说前者，那就不用吓唬人了。如果非要按照这种“唬人”的逻辑思考，那么，三餐都多吃一碗白米饭，吃30年，会增加糖尿病的风险，也堪称有毒了?

　　这个健康谣言的造谣手法，和“吃蘑菇会重金属中毒” 那个谣言非常相似。没有根据，是编些吃某种食物后死人、生病的故事，其中加入不少科学名词，再用某个外国研究者的名义来增加信任度，同时造成很强的心理暗示效果。但是这都不能改变它们的谣言本质。很可能它们只是为了吸引眼球、提高粉丝数的目标而故意编写的。但它们的效果，却是让人们的生活中增加了恐惧感，吃东西时增加心理负担，饮食平衡更加困难。同时，还会影响农业生产和销售，害到无辜的番茄种植农民。

　　说到底，哪种食物适合自己，其实很容易判断，无需听外面的传言——身体会告诉你它是否满意这种食物，只要细心倾听它的感觉就可以了。吃了某种食物是让身体更加舒服有活力了，还是让身体疲乏不适了，身体会如实的反馈给你，没有人能忽悠得了你。

4**性养生应多吃西红柿**

　　国内外科学家半个世纪的研究表明：前列腺中番茄红素浓度的减低，使其无法抵御自由基的侵蚀，使前列腺发生裂变和老化，出现病变。由于人体自身无法合 成番茄红素，随年龄增长，番茄红素的需求量也越大，从日常膳食中也很难获取人体所需要的摄入量。因此，补充外源性番茄红素成为最有效的手段。

　　2000年，美国芝加哥大学医学院对1899名中年男性近30年的调查结果显示：番茄红素摄入量越低，患前列腺疾病的可能性越高。研究证实，前列腺 疾病与人体内番茄红素的浓度水平有密切的关系。番茄红素可突破前列腺吸收屏障，直接进入腺体发挥作用。此外，美国肿瘤研究学会的一项临床试验显示，番茄红素对前列腺癌治疗有决定性作用，那些摄取番茄红素的患者，存活的5项因素得到改善。

　　目前，西方流行每天服用番茄红素胶囊。番茄胶囊为软胶囊剂型，可以突破普通药物难以吸收和全面渗透到前列腺内部的缺憾。日服剂量小、方便，对工作繁忙无法坚持服药的男性，是简单、有效的保健方式。

　　番茄红素还是心血管“护士”

　　一些研究人员指出，由于番茄红素能够有效地保护低密度脂蛋白免受氧化破坏，因而可以预防心血管疾病。

　　荷兰学者曾对66名心肌梗塞患者皮下脂肪中的类胡萝卜素含量进行测试，结果发现这些患者的番茄红素含量明显低于健康人。另有研究发现，未接受降脂治 疗的高脂血症患者，其血清番茄红素和β-胡萝卜素浓度也都低于正常人标准。可见，番茄红素在防治心血管疾病方面的作用也是不容忽视的。

　　番茄红素———延缓衰老

　　人体内有一种SOD酶，是清除人体内自由基垃圾的一种物质。人从40岁以后，SOD活性就逐渐减弱，体内垃圾难以清除，这些自由基产生的垃圾是一种 有毒的物质，是造成人体老化的有害物质。人体这时需要一些营养物质，帮助缓解人机体的衰老速度，而番茄红素正是一种可以延缓人机体衰老的物质。番茄红素中 含有20多种胡萝卜素，α胡萝卜素、β胡萝卜素、叶黄素和玉米黄素等抗氧化物质。在一些植物中，西红柿中番茄红素含量最高，每100克西红柿中，所含番茄 红素高达20毫克。　　人体的衰老与番茄红素的缺失有着密切的关系，人从40岁到60岁的阶段———预防机体衰老和躯体疾病的最好方式，就是充分地补充番茄红素。太极出品 的番茄胶囊，所含番茄红素提取自新疆天山的优质番茄，利用现代生物工程技术，突破了生食番茄家庭烹饪中番茄红素的溶解吸收障碍，可以增强人体对番茄红素的 吸收，从而延缓人体的衰老。

5**常吃西红柿有哪些好处**

　　番茄(Tomato)，别名西红柿、洋柿子。它营养丰富，具特殊风味。具有减肥瘦身、消除疲劳、增进食欲、提高对蛋白质的消化、减少胃胀食积等功效。

　　好处一：美容、防衰老。将鲜熟西红柿捣烂取汁再加少许白糖，每天用其涂面，能使皮肤细腻光滑，美容防衰老效果极佳。

　　好处二：防癌。因西红柿不仅营养丰富，且具有较强的清热解毒，抑制病变功效，坚持每天吃1-2个鲜熟的西红柿，可起到防癌和辅助治疗癌症的作用。

　　好处三：治高血压。每天早晨选1-2个鲜熟西红柿空腹蘸白糖吃，降血压效果明显。
